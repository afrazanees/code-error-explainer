# Code Error Explainer

A focused debugging assistant. Paste a traceback, compiler error, or problematic code snippet, and get a concise plain-English explanation of the cause along with a probable fix.

Interactive API documentation is automatically generated by FastAPI and available at `/docs`.

## How it works

The backend accepts the raw error or snippet at `POST /explain` and passes it to Gemini `gemini-2.5-flash` using a constrained system prompt designed to prevent conversational padding and limit explanations to under 100 words (unless code fixes require more).

## Running locally

### Prerequisites

- Python 3.11 or higher
- A Gemini API key from Google AI Studio

### Setup

1. Clone the repository and navigate into the folder:
   ```bash
   cd project-2-code-error-explainer
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Configure your API key:
   ```bash
   cp .env.example .env
   ```
   Add your `GEMINI_API_KEY` to `.env`.

5. Start the server:
   ```bash
   uvicorn main:app --reload --port 8000
   ```

6. Open `http://localhost:8000` in your browser.
7. Interactive API docs are at `http://localhost:8000/docs`.

## Deployment

This app includes a `Dockerfile` configured for deployment on Hugging Face Spaces using the Docker SDK on port 7860.
